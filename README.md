# Pokedex

Este proyecto usa React y Vite. La interfaz de la Pokedex esta en `src/pages/PaginaPokedex.jsx`.

## Iniciar

```sh
npm install
npm run dev
```

La direccion de PokeAPI se configura en `.env` con `VITE_API_BASE_URL`.

## Archivos de ejemplo

La plantilla incluye los logotipos de React y Vite en `src/assets`, una imagen de ejemplo y algunos iconos en `public`. No forman parte de la Pokedex, pero se conservan para practicar con recursos e imagenes.

## Comprobar

```sh
npm run lint
npm run build
```
